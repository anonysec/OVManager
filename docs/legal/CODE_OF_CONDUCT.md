# Code of Conduct

Be kind and direct. No harassment, hate speech, spam, or trolling —
in issues, discussions, or PRs. Technical disagreement is welcome;
personal attacks are not.

Maintainers may hide or remove violating content and, for repeat or
severe violations, block the account from the project. Decisions are
final and made to protect contributors' time.

If someone harasses you, report via GitHub Private Vulnerability
Reporting channel or the maintainer email on the repository profile.
